# cpp-daily-study

게임 서버 개발자 취업 준비용 매일 아침 C++ / 게임 서버 설계 학습 기록입니다.

- 학습 자료는 매일 Claude Docs 문서로 만들어집니다. 날짜별 링크는 `docs.md` 에 있습니다. (2026-11-16 이전 형식의 PDF는 `pdf/` 에 남아 있습니다.)
- `log.json` — 배운 개념 목록과 복습 일정 (status: unrated / weak / known, doc: 해당 날짜 문서 링크)
- `feedback.md` — 직접 남기는 피드백

## 질문하는 방법
1. 문서에서 궁금한 문장을 드래그해서 코멘트를 달고 Claude에게 보내면 그 자리에서 답이 달립니다.
2. 다음 날 아침 실행 때 코멘트가 달린 개념은 weak 로 기록되고, 질문 내용은 2주 뒤 복습 퀴즈에 나옵니다.
3. feedback.md 의 `## 미처리` 아래에 적어도 됩니다: `- 몰라요: 개념명` / `- 알아요: 개념명` / `- 질문: 개념명 - 궁금한 점`
