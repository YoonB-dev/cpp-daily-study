# cpp-daily-study

게임 서버 개발자 취업 준비용 매일 아침 C++ / 게임 서버 설계 학습 기록입니다.

- `pdf/YYYY-MM-DD.pdf` — 그날의 학습 자료 (새 개념 2개: C++ 1개 + 서버 설계 1개, 복습 퀴즈)
- `log.json` — 배운 개념 목록과 복습 일정 (status: unrated / weak / known)
- `feedback.md` — 직접 남기는 피드백

## feedback.md 사용법
`## 미처리` 아래에 적으면 다음 날 아침 반영됩니다.

- `- 몰라요: 개념명` — 2주 뒤 복습
- `- 알아요: 개념명` — 복습 제외
- `- 질문: 개념명 - 궁금한 점` — 2주 뒤 복습 때 그 질문을 퀴즈로
